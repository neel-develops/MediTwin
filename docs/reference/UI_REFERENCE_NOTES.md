# UI reference notes — current approved design

Use `meditwin_ui_reference.png` as the **only current visual reference** for the interface.

## Keep from the image
- Light blue and white theme, navy text, blue primary actions.
- Left navigation rail and a clear ward/resource heading.
- Status summary chips/cards.
- Central visual area containing stylized 3D bed models arranged in orderly groups.
- A right-side selected-resource panel with tabs or sections for details, equipment, and patient assignment.
- Search and zoom/rotate/reset controls.
- A compact dashboard area for ward counts, recent activity, quick actions, and alerts.

## Interpret carefully
- The 3D arrangement is a **display grid only**. It does not represent real-world positions.
- Groups such as Section A/B/C are automatically generated visual groups, not actual rooms or physical ward zones.
- Ward names and counts in the image are examples only. The application must show configured and stored data.
- The generated image may contain imperfect or inconsistent sample numbers/text. Do not reproduce those mistakes.

## Do not add
No realistic interior, architecture, walls, corridors, doors, windows, chairs, plants, room decorations, realistic floor plans, or exact physical locations. Do not use the older concept images that showed a realistic hospital structure; they have been superseded.
